# LinkReader 使用指南

给一批链接，自动抓正文、出摘要、译成中文，导出 txt / Markdown / Word，再给一张汇总表。
全程跑在你自己电脑上，结果只写进本机 `out/` 目录。

- **版本**　LinkReader 1.1.0
- **环境**　Windows 10 / 11，不需要装 Python（用 exe），也不需要联网注册任何账号
- **源码**　Python 标准库 + python-docx / openpyxl / pypdf；前端 Vue 3 + Arco Design Vue

---

## 一、怎么启动

### 双击 LinkReader.exe（推荐）

没有黑色命令行窗口，双击后浏览器自动打开界面。关掉浏览器标签页，后台服务会在 10 秒内自己退出，不留进程。

- 第一次运行会在 exe 旁边生成 `out/`（放结果）和 `config.json`（放大模型配置）。
- 这两个可以随 exe 一起拷走，换电脑就还是原来的配置和历史上。
- 想再开一个窗口，别重复双击 → 直接刷新已经打开的页面即可；重复双击也只会打开浏览器，不会再起一个服务。

### 双击 启动.bat（有 Python 的机器）

给要改代码的人用。会先找 Python、按需补依赖（PyPI → 清华镜像 → 阿里镜像 自动回退），再起服务。

### 命令行

```bat
python launch.py                  :: 找依赖、起服务、开浏览器
python app.py                     :: 只起服务，日志留在控制台
python app.py -p 8899             :: 指定端口
python app.py --no-browser        :: 不自动开浏览器
```

默认端口从 **8765** 往上找，被占用就顺延。

## 二、界面速览

三个竖栏，各管一件事：

| 区域 | 放什么 | 用来做什么 |
|---|---|---|
| **左栏** | 新建任务 / 工作台 / 历史任务 / 任务分组 | 换任务、翻以前跑过的批次 |
| **中栏** | 输入框 → 条目流 → 汇总条 | 贴链接、看摘要、下载单个文件 |
| **右栏** | 概览 / 本次配置 / 进度 | 看这一批用了什么参数、逐条跑到哪了 |

顶栏从左到右：品牌、当前任务名、条数、任务号、运行状态；右边是**搜索框**、**设置**、**使用指南**（就是你现在看的这个）。

窄屏自适应：小于 1180px 撤掉右栏，小于 900px 再撤掉左栏。

## 三、把链接交给它

三种给法，可以混用。

### 1. 直接粘贴

把链接贴进输入框，**一行一个**。也可以整段文字直接粘——正文里夹着的链接会被自动抠出来，重复的只留一条。

### 2. 拖表格进来

把 `.xlsx` / `.csv` / `.tsv` / `.txt` 拖到窗口**任意位置**，会出现整屏提示，松手即导入。

### 3. 点「导入表格」

输入框左下角那个按钮，走系统选文件对话框，效果一样。

### 表格里是怎么读的

不是简单按逗号切，会做这些事：

- **翻所有工作表**，不只第一张
- **读超链接单元格**——那种显示「点这里」、地址藏在超链接里的格子也能拿到
- **从混合文本里抠链接**，比如「见 https://example.com/a 第3页」
- **补全省略协议的写法**，`www.example.com/x` 会补成 `https://`
- **去重**：同一批里重复的、以及输入框里已经有的，都跳过
- **认编码**：UTF-8、GB18030 的 CSV 都能读
- **拒绝老格式**：`.xls` 会明确告诉你「用 Excel 另存为 .xlsx 再拖」，不会静默失败

导入完成后，输入框下方会有一行统计，例如：

```
「语料清单.xlsx」41 行 / 96 个有内容的单元格：识别 12 条链接，9 个站点，表内重复 2，已跳过 1 条（已在框里）
```

长链接在框里会自动折行，不会出现横向滚动条。

## 四、六个开关

在「开始抓取」按钮左边，勾选后对这一批全部生效。

| 开关 | 默认 | 作用 |
|---|---|---|
| **严格模式** | 开 | 识别到订阅墙就跳过，不写半截正文。关掉则按宽松模式保留能读到的部分，并在条目上标注 |
| **PDF 兜底** | 开 | 网页抓不到正文、或链接本身是 PDF 时，改走 PDF 解析；扫描版（纯图片）无能为力 |
| **可见窗口** | 开 | 直连 10 秒内连不上、或被 Cloudflare / Akamai 拦截时，开一个**真实浏览器窗口**打开原文取页面——真实模式比无头更不容易被机器人校验识别，实测 apnews 直连 403、真窗口 3 秒就取到 8000+ 字正文。**一条一个窗口、串行**：新开窗口 → 抓到完整正文 → 关掉窗口 → 再开下一条，桌面任一时刻只有一个抓取窗口，看得清每条在抓什么。连续 3 次没取到内容就本批停用。关掉这个开关就完全不弹窗 |
| **摘要** | 开 | 每条生成中文摘要 + 关键词。没配大模型时退回本地提取式（取首段 + 高频词），质量差一档但不用联网 |
| **翻译** | 不翻译 | 三档：不翻译 / 译成中文 / 中英对照。**翻译必须有大模型**，没配会被直接拦下并提示 |

> 翻译是按段落切分、等长回填的，段落一一对齐，不会把两段并成一段。中英对照模式下，Word 里原文排成灰色小字、译文是正文。

### 降级是怎么走的

一条链接进来，直连只给 10 秒；连不上就开真实窗口：

```
① 直接请求（10 秒）──成功──> 直接用（最快，正文最准）
   │连不上 / 403 校验页
   ▼
② 可见窗口 ──拿到正文──> 用真实窗口取的页面
   │也是拦截页 / 取不到
   ▼
   条目标「机器人校验」，展开后可点「再试一次」重开窗口手动救
```

无头渲染、截图 OCR 这两步已经移除：真窗口比无头更不容易被识别，实测它就是最有效的一级。

**只有付费墙绝不兜底。** 订阅墙、付费墙识别出来就直接剔除，不进窗口。机器人校验页（Cloudflare / Akamai 的 Access Denied）则**先交给可见窗口试一次**——直连拿到的是校验页，不代表浏览器打开也是校验页；只有窗口里仍是拦截页时才剔除。这条行为写死在代码里，不是配置项。

顺带一提：② 能顺便解决一类很隐蔽的问题。Python 发的请求不读 Windows 的系统代理设置，浏览器会读。所以有些站"Python 抓不到、浏览器打得开"，其实不是反爬，是代理没走到。这种情况下 ② 一步就过去了。

## 五、任务跑起来之后

点「开始抓取」，中栏变成条目流，右栏是进度。每条会经过这几个状态：

```
排队 → 抓取中（直连 / 可见窗口）→ 已抓取 → 生成摘要 → 翻译中 → 等待写入 → 写入文件 → 完成
```

每个状态都有清晰的含义，进度看得见：

- **抓取中**　正在试直连或真实窗口，旁边显示当前办法和已等秒数；
- **已抓取**　正文已经拿到手了，接下来只会做摘要 / 翻译 / 落盘，不会再丢；
- **等待写入 / 写入文件**　抓到的条目在排队写磁盘，轮到谁写谁就亮起「写入文件」，写完变「完成」。

**「抓取中」旁边会实时显示正在试哪种办法**，以及已经等了多少秒，例如：

```
抓取中 · 直连抓取 6s     ← 正在直接请求（最多 10 秒）
抓取中 · 转可见窗口       ← 直连被 403 拦截，马上改走真窗口
抓取中 · 可见窗口 11s     ← 真实窗口正在打开原文
```

**窗口被关掉也不会默默卡住**：抓取途中你把真实窗口关了、或者窗口崩溃退出，条目会立刻标成「**窗口关闭**」并写明原因（手动关闭 / 程序结束 / 异常退出），不会再停在「抓取中」没有提示。

**没抓到的条目可以手动救**：点开条目，右下角有「**再试一次**」。它会重新开一个真实窗口打开原文，等待上限放宽到 120 秒——这段时间你可以自己在窗口里点掉验证码、登录或者关弹窗，页面正文一出来程序就把内容取走。一次只能重试一条。「窗口关闭」的条目同样能这样救回。

所以不会再出现"卡在抓取中一动不动"的情况。跑完的条目点开还能看到**这一条试过什么**：

```
直连 10s 失败（连接失败（timed out）） → 可见窗口 8s → 已抓取
```

- **处理中**　还没轮到，或正在跑。数字会随着进度减少。
- **完成**　抓到了正文，文件已落盘。点条目能展开摘要、关键词、原文链接和下载。
- **已剔除**　按规则判定不该收的，**不是程序出错**。原因直接写在条目上：

| 状态 | 含义 | 处理 |
|---|---|---|
| 订阅墙 | 命中付费墙文案 / 元数据 / 重定向 / 正文截断，四类判定之一 | 严格模式跳过；宽松模式保留可读部分 |
| 拦截 | 返回 403 / 429，且真窗口也没取到正文 | 换时间重试，或点条目上的「再试一次」；实在不行就手动下载后当本地文件处理 |
| 机器人校验 | 直连和可见窗口**两级都**命中 DataDome / Cloudflare / Akamai（Access Denied）这类反机器人页，正文压根没下发 | 两级都没拿到才剔除；实在要这篇就人工打开后另存 HTML，或点「再试一次」重开窗口 |
| 网络不通 | 同一站点本批已连续两次连不上，后面的同站链接直接跳过 | 检查网络/代理，**别让一条链接各等一轮超时** |
| 过短 | 正文低于「最短字符」阈值 | 多半是栏目页、加载失败页 |
| 未收录 | 连接超时、域名解析不了、404，且兜底也失败 | 链接本身有问题 |

成功收录的条目还分两种来源，看左边标签：

| 标签 | 含义 | 要不要额外处理 |
|---|---|---|
| 完成 | 直接请求就拿到了 | 不用 |
| 渲染取得 | 直接请求被拦，真实窗口打开原文后拿到 | 不用，正文准确度与直接抓取一样 |

- **失败**　程序异常（网络中断、磁盘写不进等），原因同样会显示。

跑的过程中可以随时切去历史任务看别的，切回来自动接上当前进度。

## 六、看结果

### 单个条目

点开条目卡片，能看到：中文标题、原文标题、来源站点、发布日期、正文字符数、摘要、关键词、摘要方式（大模型 / 本地提取式）、原文链接、下载按钮。

顶部搜索框按标题或链接过滤；筛选条分 **全部 / 已收录 / 已剔除**，可以只看抓到的。

### 整批

中栏底部是汇总：`12 篇已收录 · 48,231 字符`，右边一个 **下载全部 zip**。

每批任务在 `out/<任务号>/` 下一个目录：

```
out/20261119-145527/
├── txt/            纯文本：标题 + 元信息 + 摘要 + 关键词 + 正文
├── md/             Markdown，带标题层级
├── docx/           Word：摘要框 + 正文，无页眉，页脚只有「第 X 页，共 Y 页」
├── 摘要汇总.xlsx    序号/标题/中文标题/来源/日期/字数/摘要/关键词/方式/翻译/链接
├── 00_索引.md      这一批的目录页
├── job.json        结构化原始数据（含逐段译文）
└── 结果打包.zip    上面这些打成一个包
```

Word 排版：A4，标题 17pt 黑体，正文 10.5pt 宋体 / Times New Roman，代码块左对齐、空行保留。

## 七、历史任务

左栏「历史任务」列出跑过的每一批，按 **今天 / 昨天 / 日期** 分组。点一下就把那批条目重新载入中栏——摘要、状态、下载链接都还在，随时能再拿文件。

任务号形如 `20261119-145527`，也可以直接用地址栏打开：

```
http://127.0.0.1:8765/#job=20261119-145527
```

## 八、接大模型（可选）

不配也能用，摘要走本地提取式、翻译不可用。想要像样的摘要和翻译，进「设置」。

| 字段 | 填什么 | 说明 |
|---|---|---|
| 接口地址 | `https://api.openai.com/v1` | **填到 `/v1` 为止**，程序自己拼 `/chat/completions` |
| 模型名 | `gpt-4o-mini` / `deepseek-chat` / `qwen-plus` 等 | 按服务商文档写 |
| API Key | 你的 Key | 只存在本机 `config.json`，不上传任何地方 |

填完点 **测试接口**，会真发一次最短请求，通了显示耗时和返回内容。

同一页还有抓取参数：

| 参数 | 默认 | 意思 |
|---|---|---|
| 并发数 | 按站点限流 | 同时抓几个，调高更快但更容易被拦 |
| 超时 | 40 秒 | 单页等待上限 |
| 最短字符 | 300 | 低于这个数算没抓到正文 |

## 九、常见问题

**双击 exe 没反应**

看 `%LOCALAPPDATA%\LinkReader\launcher.log`。端口被占、浏览器起不来都会写在这里。

**提示“Python was not found; run without arguments to install from the Microsoft Store”**

这是 Windows 自带的应用商店占位符，不是真 Python。用 exe 就不涉及；要用 `启动.bat`，得先装真 Python 并勾选 Add to PATH。

**抓到的页面只有几百字符**

多半是栏目页或需要 JS 渲染的站点。LinkReader 不执行 JS，纯静态抓取。

**返回 502 / 403**

502 是目标站点自己的网关问题，403 是反爬。这两类重试往往没用，换个来源或用浏览器另存后当本地文件处理。

**订阅墙能绕过吗**

不能，也不做。只判定并标注，不做任何绕过。

**`.xls` 老格式读不了**

加它得额外依赖且只支持到旧版格式。用 Excel 打开另存为 `.xlsx` 即可。

**任务跑到一半关掉浏览器会怎样**

exe 模式下服务会退出，已写盘的文件还在 `out/` 里；没写完的那几条下次重跑。

**结果会不会上传到别处**

不会。除了你配置的大模型接口（只有摘要和翻译的文本会发过去）和被抓取的站点本身，没有第三个地址收到数据。

## 十、边界与合规

- 只抓**公开可完整读取**的内容，遇到付费墙只做标注，不做绕过。
- 正文版权归原作者与发布机构，输出里保留了原文链接和来源，供研究、教学与语料分析使用。
- 并发默认按站点限流，请勿用于高频批量抓取同一站点。
- 所有数据落盘在本机，卸载就是删掉文件夹。
